# Security AI — DEMO

Panel de demostración online de tres módulos: computadores, servidores y páginas web.

**Seguridad:** la versión pública usa únicamente datos simulados. No admite agentes, escaneos, credenciales ni acciones de respuesta reales.

La siguiente fase será una versión privada con autenticación, aislamiento multiempresa y sensores autorizados.
